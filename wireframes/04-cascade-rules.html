Language cascade rules

One ordered preference list decides two things at once: which language Jellystructure fetches metadata in, and which audio/subtitle track becomes default. The list walks top-down per file: first match in the file's available languages wins; original resolves via TMDB; a final global fallback (default en) catches the rest.
