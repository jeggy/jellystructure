Option B · chosen direction

Combined card — one image per episode

Each episode still is picked normally from TMDB in the admin (three files → three stills). Ravilo shows the S01E01E02E03 file as a single card whose still is split by two lightly-skewed lines, so all three episode images are visible at once.

How it works

  1. Admin: the file spans E01–E03. Each episode keeps its own poster/still — pick one from TMDB just like a normal single episode.
  2. Ravilo: the three chosen stills are composed into one card as a skewed triptych — two diagonal seams divide the frame into thirds.
  3. Playback & watched: one continuous file → one play action, all three mark watched together (Option B behaviour).
