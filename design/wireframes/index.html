Jellystructure

A self-hosted control panel that replaces Jellyfin's built-in metadata scraper. You manage NFO files, artwork, and the media files themselves (audio / subtitle track order) from one place — then tell Jellyfin to reload. These are rough sketches to agree on layout and flow before any pixels are polished. The real app targets dark mode; here we stay in marker-on-paper so we argue about structure, not colours.

Goal: never click "Refresh Metadata" inside Jellyfin again. Everything lives here.
Built Kotlin Native (backend) + Kotlin WASM → real DOM (frontend). Updates stream in live over WebSocket.
The killer feature: per-file language cascade + a triage list of tracks missing a language tag.

The app shell — two navigation directions

Same dashboard content, two ways to get around. This decides the skeleton every other screen hangs on.
