Audio & Subtitles — friendly picker overhaul

Same job as today's in-player picker, rebuilt so no technical knowledge is needed to turn on subtitles. Country flags anchor every language, labels are plain, and every track stays available — nothing is hidden. Codec names (PGS, E-AC3, mov_text…) never appear. Below: four layout directions, each shown on TV and phone. All four share the same friendly vocabulary and carry across the Aurora / Midnight / Noir skins.

Signs only

A forced track. Only translates on-screen text & foreign lines — not the whole film.

Sound described

SDH, in plain words. Adds speaker names & sound-effect notes for deaf / hard-of-hearing viewers.

Describes action

An audio-description track (Synstolkning). Narrates what's happening on screen.

Starts in a moment

The only cost cue. This subtitle needs a few seconds to start — no explanation of why.

Default Surround 5.1

Kept because they help you choose: the source's suggested track, and surround vs. stereo.
