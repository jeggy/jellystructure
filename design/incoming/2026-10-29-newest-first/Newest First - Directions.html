Newest first

A series where only the latest episodes matter — TV and phone series page, the Continue tile, the end of an episode, and the admin switch.
Round newest-first · revision 1 · 2026-10-29 · Rannvá

This round is ideas for the owner to choose from. No spec is adopted, so every rule drawn here is a lean, not a requirement. It draws only what a newest first series changes — the series page, Home’s Continue tile, the end of an episode and one admin setting. Nothing else on those screens is redesigned.

What is fixed

These are not up for choosing; they are the ground the directions stand on.

  • The admin renders server-pushed state only. The switch shows what the server stored. Nothing on a Ravilo screen is computed from the dates by the client — so every direction here needs the order to arrive as a field, and none of them can be done in the client alone.
  • TV: everything reachable by D-pad, visibly focused, readable at 3 m on 1080p. Tizen uses the TV layout. The Chromecast receiver has no series page and is out of the round.
  • Never colour alone for New or for the newest-first mark. Each carries a word, and the drawn words are shipped i18n strings wherever one exists.
  • The repository is public. Dagbók, Anna and the invented stills are the whole corpus; no real programme, broadcaster or picture appears anywhere.
  • The wire stays backwards compatible. Every direction below adds a field; none retypes or removes one an installed client reads.

The directions

A — the Newest first bundle the brief’s lean

One series-level flag changes four things at once, and they only make sense together:

  • the rail runs newest first, Thursday leftmost;
  • each card’s main label is the air date, with the programme’s own heading under it;
  • the primary button is Play newest · Thu 29 Oct, or Resume when today’s is part watched;
  • Shuffle, Start over and x of 12 watched are gone, and the hero carries one mark saying the series runs newest first.

What it gives: the owner’s ask, exactly and in one place — the newest is first and Play plays it. What it costs: a stored per-series setting, a page that behaves differently from every other series, and four removals that each need a reason a viewer would accept.

C — the viewer’s own sort control

Today’s page plus a Newest first / Oldest first control on the Episodes header, reachable by D-pad. Play still follows today’s rule.

What it gives: no admin switch, no Auto-fetch involvement, nothing series-specific, and it helps every series rather than one kind. It is by far the cheaper build. What it costs: it answers half the ask. The owner asked for two things — “the newest episode is listed first” and “when you click play, it would play the newest” — and C does the first only. It also keeps Shuffle on a daily programme and keeps a watched count that describes a different twelve episodes tomorrow. See newest-c-tv-c2: the rail is reversed and the button still reads Play · S2026E291.

Drawn and not drawn. Drawn: the round’s own four states, 10-foot focus on every TV frame, the longest string, Danish and Faroese, and a non-aurora skin. Not drawn, and deliberately: loading, empty, error and offline. None of them is reached by this round — the order is a field on a series page that already has all four, and a newest-first series does not load, empty, fail or go offline differently from any other. If a direction is adopted, those four stay the series page’s own and need no new picture.

Decided rows

Judgement calls made inside the round, each one a thing the owner could overturn without redrawing anything else.

rowdecidedwhy
the hero markdrawn — one pill, ↓ Newest first A reversed list with no explanation reads as a bug in a library where every other series runs forwards. It is the shipped .dnext pill in dim ink, so it is a property of the series rather than a control; the words are the shipped browse.sort.newest and the arrow is a stroked path, so nothing is carried by colour.
the state pillcarries no date The button under it already names the episode. On today’s page both say a six-character code and the repetition is cheap; here both would say a ten-character date twice, a centimetre apart. The pill owns the state word, the button owns the date.
the NEW ribbononly when something older is watched On a series nobody has started every episode is equally new, so a ribbon on the newest one is decoration on an arbitrary card. “New” means “newer than where you got to”, which needs a place you got to. Compare newest-a-tv-s1 and -s2.
the corner numberremoved from A’s stills The shipped .ep-num draws the episode number at 40 px. 302 means nothing on a daily programme, and the day of the month would repeat the label directly beneath it. The duration and the ✓ stay.
s4’s sentenceCaught up, not All 12 episodes watched The shipped detail.all_watched counts a set that is different tomorrow. Caught up is a statement about the viewer, which is the thing that stays true overnight.
C’s controltwo pills, not one that cycles A D-pad user has to see the option they are not on. A single pill that flips is a control whose other half is invisible until it is pressed.
the admin controlthe shipped .seg, no new class The brief preferred an existing segmented control and one fits exactly. The only new CSS is the row’s geometry and the dashed rule that marks the provenance line as the server’s.
the provenance linedrawn on both values A line that appears only when Auto-fetch set it reads as that value being special rather than as one of two an operator may pick. On the hand-set value it says who set it last and that the fetcher will not set it again — the thing an operator would otherwise fear.

Still open

  • Decision 1 — how a series is marked. A (an admin switch, defaulted by Auto-fetch for a date-numbered series) or C (the viewer’s own sort). Pictures: 1 + 5 for A, 1C for C.
  • Decision 2 — what Play does. The newest even when watched (A, as drawn), or the newest unwatched. newest-a-tv-s4 is the whole of it: the alternative has nothing to name in that state.
  • Decision 3 — the end of an episode. Stop and go back (A), or Up next to the next newer episode (B). Both drawn; they cannot both ship.
  • Decision 4 — labels. The air date in place of the code, with or without the code as a secondary line. newest-a-tv-s1 against -s1-code.
  • C’s selected state is weaker than its focused state — see the report. If C is picked this needs settling before it is built.
