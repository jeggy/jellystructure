Auto-fetch’s missing states

Round auto-fetch-states, revision 2 · 2026-10-25. Drawn in this repository. Round 2 drew the Fetchers tab and its design stands; this round draws only what round 2 did not. It redraws nothing and promotes nothing.

What is fixed

  • The frontend renders server-pushed state only (constitution, Real-Time UI Contract). Every state here is one the server sends. Checking the site… is what the server says is happening, not what the admin hopes will happen.
  • A control that cannot do anything new is shown, disabled, with its reason — never hidden and never live-but-useless (processing-runs-as-nine-features.md FR-11, carried in by FR-1.2). Drawn as .af-dis: half opacity and a dashed edge, which is processing.css’s own look for the same thing.
  • A stop is never retried automatically (FR-2.5). No countdown and no retrying in… appears anywhere in this round.
  • Never express state by accent colour alone. Every state here is a word first.
  • 1440 and 412, both themes. Every --ok/--warn/--bad/--info used as a text colour has its [data-theme="light"] twin, as processing.css does.
  • Canvas substitutions, both deliberate: --blur: none inside every frame (backdrop-filter is production CSS and breaks the screenshot render; the live admin keeps its glass), and .af-step.run .ic::after’s infinite rotation switched off — which is the whole point of the step-marker work below.
  • The stand-in corpus only. No episode name is invented. Where a Royndin row has to show what TMDB holds it shows TMDB’s air date, because a date is a fact we can state without inventing a title.

One direction, and one real fork

Everything in this round is drawn as a single direction except the Investigating step marker, where the brief says there is no lean. That one is drawn twice.

States from the house list, and what was skipped

  • Loading — skipped. Round 2 owns the page’s first paint and this round adds no new surface that loads on its own.
  • Empty — skipped. .af-empty is round 2’s and unchanged.
  • Error — drawn, four times: Site stopped, Needs re-investigation, the failed proof, and a failed investigation step.
  • The longest string — drawn, in stopped-reasons, in Faroese.
  • Danish and Faroese — the four stop reasons are drawn in Faroese; every other new string is drafted in the table below rather than rendered.
  • 10-foot focus — not applicable: admin only.
  • Offline — skipped. ai.html’s .ai-offl strip is the page’s lost-socket state and is round 2’s. It would dim Resume site, Propose and Accept along with everything else, which needs no new drawing.

What the promotion of ai.css will have to carry

That is a separate task and this round promotes nothing, but the work is listed here so it does not have to be re-derived:

  • Delete .af-step.run .ic::after and @keyframes af-spin. They are the only infinite animation on the page.
  • Add the new af-* rules from auto-fetch-states.css, and the [data-theme="light"] twins with them — the twins are hand-authored and want a line in check-mobile-css.sh.
  • .badge.flat is needed by two page stylesheets now (processing.css has its own scoped copy). It belongs in wf.css, not in a third page file.
  • .af-tbl needs the ≤640 px card-per-fetcher tier, and the row cells need the class names this round gives them (sched, st, q, tg, acts-cell).
  • .af-map needs the ≤640 px row-per-mapping tier and its cell classes (item, arr, se, tmdb, why, lib), and .af-kv needs the ≤640 px stack.
  • .af-det-in > * { min-width: 0 }: without it the read-only recipe widens the page at 412.
  • The open row needs the .af-open wrapper around the band and the detail.
  • Carry the --ink-dim light-theme fix into the four-mark legend as well as the step list — the legend's waiting 4 is still faint there (Bárður, 2026-10-25).
  • ai.css’s wrapper class must cover all of the above — .badge.flat, .af-* and the light twins alike.
