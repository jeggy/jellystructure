Cross-seed safety

qBittorrentenable guard
When enabled, Jellystructure checks qBittorrent before any mkvpropedit/ffmpeg edit and blocks writes to a file that is currently being seeded, so torrent hashes (and cross-seeds) don't break. Leave this off and there is no guard — cross-seed safety is simply not part of media management, and all track/NFO edits proceed without checking qBittorrent.
⛨ Seeding guard off — edits are never blocked. Turn it on to connect qBittorrent and protect seeded files.
