Continue Watching — hide titles tagged…

A tag condition on each Continue Watching system row: on Home, in a collection with its own rows, or in a user's own layout. The row stays exactly as Newly Added Movies and Newly Added Series are drawn; the only addition is one small sub-row beneath it. Admin-only. No Ravilo change: the TV, phone, desktop and browser receive a shorter row and a See all that matches it.

Q1 · Q4
Every Continue Watching row has its own tags

The Home row has its tag list. A collection set to Same as Home reuses the Home rows, and with them the Home tags — there is nothing to set inside it. A collection set to Custom has its own Continue Watching row, and its tags are picked again there. They can differ from Home's or be empty. If that collection's Continue Watching is off, there is no sub-row. Olivar is such a collection. The same applies to a user's custom layout (Eyð).

Q2
Picker with nothing typed: the most-used tags

The six most-used tags, by title count, until a letter is typed.

Q3
No new Save

The tag list is part of the layout and is saved by the existing Save, along with every other layout change.

Q6
There are no kids profiles

There are only configurations: collections, content rows, and users with overridden layouts. "Kids" is just a user name in the stand-in data.

Unchanged from the brief

  • Exact tag name, case-insensitive, on the movie or the series. A series tag hides both its resume cards and its next-up card.
  • Hiding happens before the 20-card cap. The row and See all never disagree. An empty row is omitted.
  • Progress is never touched. The title stays everywhere else, and Resume still works on its own page. The picker can't create a tag.

Also decided

Q5
A tag carried by 0 titles — kept as drawn

The chip shows its count, 0, in amber. No sentence.

Q7
Continue Watching switched off — sub-row hidden, tags kept

While the row is off its sub-row isn't shown, but the saved tags stay. Switching the row back on brings them back unchanged. Nothing is shown greyed out.

Nothing is left open.

Ravilo TV · 10-foot · the result

Fewer cards, nothing else

The server sends a shorter row; the client is unchanged. It's the same screen with the same focus on the first card. The strip under each frame shows the whole row, including the part off-screen. A user on the global layout, with the Home row hiding kids-tv: 8 → 5 (cards 1, 3, 5, 7, 8). Eyð's own layout hides kids-tv and cartoons: 4 (cards 1, 3, 5, 7). If every card is hidden, the row and its header are omitted and Newly Added takes first focus, still carrying the hidden titles. See all lists the same 5 cards and says nothing.
