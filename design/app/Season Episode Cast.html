What counts as “main cast”?
It comes straight from TMDB — no guesswork. The series cast is TMDB aggregate_credits, kept in TMDB’s own order (billing order); the ▸ N eps badge is each role’s total_episode_count.
Written verbatim to tvshow.nfo. You can still reorder, edit a role, remove or add a person — manual changes are preserved across re-fetches (like JS tags) and marked with a small edited tag, so a re-pull never clobbers your curation.

Series holds the main cast; each episode holds its guest stars + crew. Profile images cached & served (Phase 75). Write-through: edits persist immediately.
↓ Save → NFO
③ NFO files on disk
tvshow.nfo ← main cast.
episodedetails.nfo ← main cast (resolved) + guest stars + <director>/<writer>, each <actor> with <order> + <thumb>.
↓ Sync (refresh)
④ Jellyfin
Reads each <thumb> URL and downloads the photo into its People store. Series page shows main cast; episode pages show cast + guest stars.
