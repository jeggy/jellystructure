Certifications arrive from NFO and TMDB in every country’s own system — G, TV-MA, Från 15 år, Btl… Map each raw value to one normalized age (0–18). Ravilo’s Maturity filter and kids profiles use only the number — a title rated PG-13 simply becomes 13+, nothing is ever shown as “G” or “TV-PG”, and anything with no (mapped) rating is treated as 18 when filtering — never shown as an 18+ badge, and still listed when no maturity range is set. Changes are written through immediately.
