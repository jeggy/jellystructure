System rows (Continue, Newly Added) sit at the top — toggle or rename them, but they can’t be removed. Everything below is a workbench-filter row you build with conditions. This set is reused inside every channel view, scoped to that channel.

Top 10

Radarrshow this tab

Adds a Top 10 tab on this user's TV with trending charts from a third-party source. Each entry shows whether it's already in your library, currently being fetched, or requestable — a Request then grabs it through Radarr and Jellystructure organises it. Requires Radarr to be connected in Settings → Download tools.

Allow this user to request downloads
Off = they browse charts & see status, but can't start a fetch. Admins can always request.
