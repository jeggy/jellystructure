AI features need an API key

Add one under Settings → Connections and this page appears in the sidebar. Nothing here runs without it, and no page content is ever sent anywhere until you start an investigation.

Open Connections

Auto-fetch turns a web page that hosts a series into a scheduled download. You give it the page and the TMDB id; the model works out how the videos are served, picks the highest quality, checks it really is a series, and writes a script that is safe to run again and again. New episodes usually land here before TMDB knows them — the fetcher still files them by season and episode, and carries the episode name, overview and a still across from the source page so you can add them to TMDB in one go.
